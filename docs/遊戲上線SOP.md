##### **🟩【Phase 2: 遊戲開放】**

###### **📄【基本設定 - 必填】**

─────────────────────────────────────

**遊戲狀態改為開放**

1. 進入後台 → 已上架遊戲（或敬請期待遊戲）
2. 點選「操作」
3. **遊戲狀態改為「開放」**
4. 確認開放日期

**地區設定確認**

1. 確認地區限制是否需要調整
  - 是 → 更新限制地區
  - 否 → 保持現狀

---

###### **📄【展示相關確認】**

─────────────────────────────────────

**大廳顯示確認**

1. **大廳同步顯示時間** → 最終確認是否顯示
2. **預告倒數計時** → 移除或更新

**圖示 & 標籤最終確認**

1. **圖示種類彩金** → 最終確認
2. **圖示種類** → 最終確認
3. **遊戲活動 icon** → 最終確認
4. **遊戲標籤** → 確認是否調整

**介紹內容最終版**

1. **玩法介紹** → 確認無誤
2. **介紹文章** → 確認官網連結正確
3. **介紹圖片** → 最終確認
4. **推薦遊戲資訊** → 確認最新文案

---

###### **📄【功能確認】**

─────────────────────────────────────

**機台保留功能確認**

1. **上線週期檢查**
  - 是否已過第一週？
  - 是 → 開放保留功能
  - 否 → 保持限制

**預約 & VIP 功能**

1. **預約功能** → 確認摺疊狀態正確
2. **金幣 VIP 層級** → 確認配置
3. **金幣管玩家等級** → 確認運用狀態

###### **📄【常見問題】**

─────────────────────────────────────

**Q: 敬請期待期間用戶會看到什麼？**

A: 用戶會看到遊戲的預告資訊、敬請期待倒計時、推薦資訊等，但無法進入遊戲。

**Q: 第一週機台保留功能是什麼？**

A: 遊戲上線的第一週，體驗廳用戶不能進行機台保留操作。

**Q: 圖示種類彩金要問誰？**

A: 問數學（見上方「待確認項目」表）

**Q: 何時從敬請期待改成開放？**

A: 等到敬請期待日期到期，或根據業務需求決定開放時間。
